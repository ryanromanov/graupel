Outline rules

Each syntax has rules that pick the lines that appear in the outline. To change them, open the syntax in the syntax editor and click Outline. Syntaxes that use tree-sitter have fixed rules, so the pane is locked.

Rules

Click the Add (+) button to add a rule, then fill in:

  • Regular Expression Pattern: a regular expression. Each match becomes an outline item.

  • Display Pattern: how the item is titled. Leave it empty to show the whole match, or use $0 for the whole match and $1 to $9 for the captured groups. To show a literal $1, type \$1. Graupel trims leading indentation and extra spaces from the result.

  • Kind: the icon next to the item (see below).

  • IC: ignores case when matching.

  • Description: a note for yourself.

For example, Boreas lists functions and subroutines with this pattern, with Kind set to Function and IC on:

^[\t ]*(function|subroutine)[\t ]+[a-z_][a-z0-9_]*

Kinds

KindForExamples
Container

Something that holds other items

class, struct, module
Value

Properties, fields, constants

let, const, enum cases
Function

Functions and methods

func, def, subroutine
Title

The title of a document or figure

<title>, <figcaption>
Heading

Section headings. Give a level from 1 to 7 to nest items under each other, so you can collapse them.

<h1>, \section{}
Mark

Markers you write to group code

MARK:, #pragma mark
Separator

A divider line that can’t be selected

<hr>, MARK: -
None

No icon
