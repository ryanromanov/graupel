See problems in your code

When a language server checks your document, Graupel underlines the problems it finds as you type. This works for any language with a language server, such as Boreas. See Language servers.

Read a problem

  • Hold the pointer over the underlined text to see what’s wrong.

  • Or move the insertion point into the underlined text. The status bar at the bottom of the window shows the message.

The color of the dotted underline tells you what kind of problem it is:

UnderlineKind
Red

An error. The code won’t run as written.

Orange

A warning. The code runs but probably doesn’t do what you meant.

Blue

Information from the server.

Gray

A hint, such as a shorter way to write something.

The server checks again a moment after you stop typing, and the underlines move or disappear to match. What counts as a problem, and how many are reported at a time, depends on the server.

If nothing is underlined

If the status bar says the server isn’t installed or has stopped, see If a language server isn’t working. Otherwise, the server found no problems.
