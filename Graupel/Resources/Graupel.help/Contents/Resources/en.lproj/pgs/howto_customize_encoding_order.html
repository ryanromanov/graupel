How Graupel detects encodings

A file doesn’t say what encoding it’s in, so Graupel works it out when it opens the file. It checks these in order:

  1. A byte order mark (BOM). Some UTF-8 and UTF-16 files start with one.

  2. The encoding saved with the file. Some Mac apps, including TextEdit, record the encoding in the file’s extended attributes.

  3. A declaration in the text, if you turned that on (see below).

  4. The encoding list. Graupel tries each encoding on the list, from the top, and uses the first one that reads the whole file without errors. See Change the encoding list.

If Graupel guesses wrong, choose the right one yourself. See Open a document in a different encoding.

Use the encoding a file declares

HTML, CSS, XML, Python, and other files often name their encoding near the top, such as <meta charset="utf-8"> or # -*- coding: latin-1 -*-. To have Graupel use these, choose Graupel > Settings, click Format, then select Refer to encoding declaration in document.

Graupel looks only at the first 1,024 bytes of the file. It recognizes charset= in HTML and XML, @charset at the start of a CSS file, and encoding:, encoding=, or coding: in the first two lines. It uses the first one it finds.

If a file mentions an encoding that isn’t its own, for example in an example near the top, put the real declaration first or turn this setting off.

Change the encoding list

The encoding list sets which encodings appear in Format > Text Encoding and the status bar, and in what order. Graupel also tries them in this order when it detects a file’s encoding, and it only considers encodings that are on the list.

Change the list

  1. Choose Graupel > Settings, then click Format.

  2. Next to Encoding priorities, click Edit List.

  3. Do any of the following:

    • Drag encodings up or down. Put the ones you use most near the top.

    • To add an encoding or a separator line, select where it should go, click the Add (+) button, then choose it.

    • To remove encodings, select them, then click the Delete (−) button.

    • To go back to the original list, click Restore Defaults.

  4. Click OK.

Tips

  • Keep encodings you might need to open, even if you never save in them. Graupel won’t detect an encoding that isn’t on the list.

  • Put Unicode (UTF-16) below the encodings you use. Almost any file can be read as UTF-16, so if it’s near the top, Graupel picks it when it shouldn’t.

  • For Japanese files, pick the Shift JIS variant you need. Japanese (Shift JIS) is the safest choice; Japanese (Shift JIS X0213), Japanese (Mac OS), and Japanese (Windows, DOS) each add characters, and they store the yen sign, backslash, and tilde differently.

  • Unicode (UTF-8) and Unicode (UTF-8) with BOM always stay together, and you can’t remove them. The encoding set as Default text encoding can’t be removed either.
