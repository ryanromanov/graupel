Print a document

  1. To print part of a document, select it first.

  2. Choose File > Print.

  3. Set the options, then click Print. To make a PDF instead, choose Save as PDF from the PDF menu at the bottom of the dialog.

Graupel’s print options

The Graupel section of the Print dialog sets how the text looks on paper. To use the same options again, save them as a preset with the dialog’s other settings.

OptionDescription
Font Size

The size of the printed text.

Color

Print in the colors of a theme, or choose Black and White.

Print Backgrounds

Print the theme’s background color too.

Print Line Numbers

Print a number before each line.

Print Invisibles

Print invisible characters.

Print Headers and Footers

Print a line at the top and bottom of each page. For Header and Footer, choose what to show and where: the syntax name, document name, file path, print date, last modified date, or page number.

For the options every Mac app has, see Print documents from your Mac.
