Open folders

Open a folder to work on the files in it from one window. The folder’s files appear in a sidebar, and the file you click opens in the window. The sidebar is only for folders; a window that opened a single file can’t show one.

Open a folder

  • Choose File > Open, select the folder, then click Open.

  • Drag the folder onto the Graupel icon.

Work with the files

  • Click a file in the sidebar to open it in the window, in a tab.

  • To find files by name, type in the filter field at the bottom of the sidebar. To show all files again, clear the field.

  • To show files that are normally hidden, Control-click in the sidebar and choose Show Hidden Files. See Open hidden files.

Use tabs

  • Clicking a file opens it in a temporary tab, with its name in italics, which the next file you click replaces. To keep the tab, double-click the file or the tab, or edit the file.

  • To close a tab, click its ×, or choose File > Close Tab (Command-W). A dot in place of the × means the file has unsaved changes. To close the window with all its tabs, choose File > Close Window (Shift-Command-W).

  • To move to the next or previous tab, press Shift-Command-] or Shift-Command-[, or Control-Tab or Control-Shift-Tab. Command-1 to Command-8 select a tab by its position, and Command-9 selects the last one.

  • Drag a tab to move it. Control-click a tab to close it or the other tabs, to open its file in a new window, or to show it in the File Browser.

  • The tabs have a row of their own. To put them in the top bar with the buttons, choose View > Tab Rows > One Row.

  • When the tabs don’t all fit, scroll along them, or click the arrow at their end to list them. To make them narrower instead, change When tabs don’t fit in Appearance settings.

Files that aren’t text

When you click a file that isn’t text, such as an image or a PDF, the window shows information about it and a preview. From there you can:

  • Open it in another app with Open with External Editor, which lists the apps that can open it.

  • Open it in Graupel anyway with Open as Plain Text.

  • For an alias or symbolic link, show or open the original. See Open aliases and symbolic links.
