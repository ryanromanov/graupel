If a language server isn’t working

When a language server can’t run, the status bar at the bottom of the window says so. Hold the pointer over the message to see the reason.

“Server not installed”

Graupel can’t find the server’s command.

  • Install the server. To see which command Graupel looks for, choose Graupel > Settings, click Language Servers, and select the language.

  • If the command works in Terminal, find where it is with which, for example which boreas, and type that full path in Command.

  • If you installed the server while Graupel was open, quit Graupel and open it again. Graupel reads your shell’s PATH once, when it opens.

“Server stopped”

The server started but quit because of an error. The reason shown is the last message the server reported.

  • Check that the command is right, including its options, by running it in Terminal. A server that works waits for input instead of quitting.

  • After fixing the problem, click Restart in Language Servers settings.

Graupel doesn’t restart a stopped server by itself, so that a server that fails right away doesn’t run again and again.

No underlines and no message

  • Check the document’s syntax in the toolbar, or choose Format > Syntax. Graupel uses the server for the document’s syntax, so a Boreas file opened as plain text isn’t checked.

  • In Language Servers settings, check that Check language files as you type is selected.

  • If the status says the server is running, it found no problems.
