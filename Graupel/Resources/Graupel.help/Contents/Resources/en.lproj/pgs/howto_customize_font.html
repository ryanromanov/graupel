Change fonts

Graupel has two fonts: a standard font and a monospaced font. Code uses the monospaced one and other documents use the standard one, unless you change that in Mode settings.

Choose the fonts

Choose Graupel > Settings, click Appearance, then click Select… next to Standard font or Monospaced font. The same pane sets Line height, Ligatures, and Antialias.

Change the font in one document

These changes last until you close the document. A plain text file can’t store a font, so the next time you open it, it uses the font from Settings again.

  • Bigger or smaller text: Choose Format > Font > Bigger or Smaller, pinch on the trackpad, or use the Text Size item in the toolbar. To go back to the usual size, double-tap with two fingers.

  • The other font: Choose Format > Font > Font Type > Standard or Monospaced.

  • Any font: Choose Format > Font > Show Fonts, then choose a font in the Fonts window.

  • Ligatures and smoothing: Choose Format > Font > Ligatures or Antialias. Ligatures appear only with fonts that have them.

To undo all of these, choose Format > Font > Reset to Default.
