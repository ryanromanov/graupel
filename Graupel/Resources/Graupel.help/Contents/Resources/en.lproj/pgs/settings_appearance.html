Appearance settings

Choose Graupel > Settings, then click Appearance.

SettingWhat it does
Standard font, Monospaced font

The two fonts the editor uses. Click Select… to choose a font and size. Antialias smooths the edges of the letters, and Ligatures joins letter pairs that the font draws as one, such as “fi” or “->” in some coding fonts. Which documents get which font is set in Mode settings. See Change fonts.
Line height

The space from one line to the next, as a multiple of the text size.
Appearance

Whether document windows are light or dark. Match System follows your Mac.
Status bar

Tinted lets the editor’s color show through the status bar. Opaque gives it a solid background.
Editor opacity

How much of what’s behind the window shows through the editor.
Theme

The editor’s colors. Select a theme in the list to use it; the colors appear on the right, where you can change them. The ••• button and Control-click have Duplicate, Rename, Restore, Export…, and Import…. See Change the colors.
