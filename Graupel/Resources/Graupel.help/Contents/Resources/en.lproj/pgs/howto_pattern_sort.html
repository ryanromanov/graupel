Sort lines by part of each line

Text > Lines > Sort sorts whole lines alphabetically. To sort by a column or by text a regular expression finds, use Sort by Pattern.

Sort lines

  1. Select the lines to sort. If nothing is selected, Graupel sorts the whole document.

  2. Choose Text > Lines > Sort by Pattern.

  3. Under Sort key, choose what to compare (see below). Sample shows which part of a line will be compared.

  4. Choose the sort options, then click Sort.

Sort keys

  • Entire line compares whole lines.

  • Column splits each line at a separator and compares one piece. In Delimiter, type the separator; it’s a comma if you leave it empty, and \t means tab. In Position, type the column number, counting from 1. Spaces around the separator are ignored.

  • Regular expression compares the text the Pattern matches. To compare only part of the match, select Use captured group and type the group’s number. Ignore case here affects only the matching, not the sort.

Sort options

OptionWhat it does
Ignore case

Sorts upper- and lowercase letters together.

Respect language rules

Sorts in the order your language expects, so letters with accents sort next to the same letters without them.

Treat numbers as numeric values

Puts “file5” before “file12”.

Keep the first line at the top

Leaves the first line in place, such as a header row.

In descending order

Sorts from Z to A.
