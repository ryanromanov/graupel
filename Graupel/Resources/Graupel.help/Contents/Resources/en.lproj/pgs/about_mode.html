Editor modes

Writing notes and writing code want different things from an editor. A mode is a set of editor settings that Graupel picks by the kind of document you open.

A mode sets:

  • Whether to use the standard font or the monospaced font

  • Substitutions, such as smart quotes and text replacement

  • Spelling and grammar checking

  • Which words to suggest, and whether to suggest them as you type (see Complete words)

  • Indentation: tabs or spaces, and how wide

To change modes, see Mode settings.

How Graupel picks a mode

Every syntax is either a general kind or a code kind. Plain text, Markdown, and LaTeX are general. Swift, Python, and Boreas are code. Graupel uses the General or Code mode to match.

If one syntax needs something different, add a mode for that syntax in Mode settings. That mode wins over the kind’s mode. For example, Markdown is general, so it uses the standard font. A Markdown mode could switch to the monospaced font and keep spell checking on.
