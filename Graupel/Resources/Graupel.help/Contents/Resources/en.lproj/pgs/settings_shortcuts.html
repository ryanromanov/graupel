Change keyboard shortcuts

You can change the shortcut for any menu command.

  1. Choose Graupel > Settings, then click Shortcuts.

  2. Find the command, click its Key column, then press the new keys. Press Delete to remove a shortcut.

If the shortcut is already used by another command, or can’t be used, Graupel says so and keeps the old one. To undo all your changes, click Restore Defaults.

Shortcuts that are set elsewhere

  • Snippets: Set a snippet’s shortcut in Snippets settings.

  • Scripts: Add the shortcut to the script’s file name. See Arrange the Script menu.

  • Some commands macOS provides, such as the Services menu: Change these in System Settings. See Create keyboard shortcuts for apps on Mac.

If a shortcut doesn’t work

Graupel can’t catch every conflict. A script or snippet might use the same shortcut as a menu command, and then only one of them runs. Some keys with Option or Shift also type a character, and typing wins. Try a shortcut that includes Command or Control.
