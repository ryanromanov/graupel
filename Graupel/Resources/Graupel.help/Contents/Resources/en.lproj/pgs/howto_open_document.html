Create or open documents

Graupel edits plain text: text with no fonts, colors, or images in it. Source code, Markdown, HTML, and .txt files are all plain text, including ones made in other apps.

Create a document

Choose File > New. When Graupel opens with no other documents, it also creates a new document; to change that, use When nothing else is open in General settings.

Open a document

  • Choose File > Open, select the document, then click Open. To pick the text encoding Graupel reads the file with, see Open a document in a different encoding.

  • Drag the document onto the Graupel icon in the Dock or the Finder.

  • Double-click the document in the Finder, if Graupel is the app that opens that kind of file.

Graupel edits only plain text. It will open other files, such as PDFs, images, or Word documents, but shows their raw contents, which are mostly unreadable. Open those in the app made for them.

To open a folder and switch between its files in one window, see Open folders.

Open hidden files

Some files, such as .gitignore or .zshrc, are hidden in the Finder. Graupel can show them so you can open them.

  • In the Open dialog: Choose File > Open, then select Show invisible files.

  • In a folder’s sidebar: Control-click in the sidebar and choose Show Hidden Files. Choose it again to hide them.

Open aliases and symbolic links

An alias or a symbolic link points to a file or folder somewhere else. Graupel opens what it points to, called the original.

  • From the Finder or the Open dialog: Open the alias or link like any document. Graupel opens the original.

  • In a folder’s sidebar, for a file: Click the alias or link. Graupel opens the original in the window. If the original isn’t text, Graupel shows a preview; click Open Original to open it anyway.

  • In a folder’s sidebar, for a folder: Click the alias or link, then click Open in New Window. The sidebar can’t show the original folder’s files in place.

To see where the original is, click Show in Finder in the preview.

Open a document without changing it

You can stop a document from being edited while you read it. This lasts until you close the document; the file itself doesn’t change.

  • Choose Format > Prevent Editing. To edit again, choose Format > Allow Editing.

  • To open a document this way, choose File > Open and select Open as read-only, or use the --readonly option of the graupel command.

While editing is prevented, a pencil with a slash appears in the status bar.

To lock the file itself, so that no app can change it, move the pointer to the right of the document’s name in the title bar, click the arrow that appears, then select Locked.
