How Graupel picks a syntax

When you open or rename a document, Graupel checks these in order and uses the first syntax that matches:

  1. The whole file name. Makefile gets Makefile and .htaccess gets Apache. Upper and lowercase must match.

  2. The file extension. .py gets Python and .bor gets Boreas. Case doesn’t matter, so .HTML works too.

  3. A #! line. If the first line starts with #!, Graupel uses the program it names. #!/usr/bin/perl gets Perl. With env, it uses the word after it, so #!/usr/bin/env python3 gets Python.

  4. An XML declaration. A file that starts with <?xml gets XML.

  5. The file type. A file the Mac knows as a kind of JSON, such as .geojson, gets JSON.

If nothing matches, the document gets None, with no highlighting.

If two syntaxes match at the same step, one you made or changed wins over a built-in one.

Change which files use a syntax

Open the syntax in the syntax editor, click File Mapping, then add or remove extensions, file names, or interpreters.

Conflicts

If you give two syntaxes the same extension, Graupel lists it as a conflict. To see conflicts, go to Format settings, click the ••• button below Available syntaxes, then choose Show File Mapping Conflicts. If the item is dimmed, there are none.

A conflict only matters if a document opens with the wrong syntax. If it does, remove the extension from the syntax you don’t want.
