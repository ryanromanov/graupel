Run a command by typing

Quick Actions finds any menu command, or any script in the Scripts menu, from a few letters of its name.

  1. Choose View > Show Quick Actions or press Command-K.

  2. Type part of the command’s name. You can skip letters: “shr” finds Shift Right. To narrow it down, type part of a submenu’s name first, then a space, as in “indent right” for Text > Indentation > Shift Right.

  3. Press Up Arrow or Down Arrow to choose a command, then press Return.

Each command shows its menu and its keyboard shortcut, if it has one. To close Quick Actions without running anything, press Esc or click outside it.
