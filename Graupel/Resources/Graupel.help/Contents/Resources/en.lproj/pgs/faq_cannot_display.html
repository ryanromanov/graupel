If a document looks garbled

Text full of odd symbols, such as “Ã©” where “é” should be, usually means Graupel read the file with the wrong text encoding. The file itself is fine as long as you don’t save it.

  • Open it again with the right encoding. Choose Format > Text Encoding, choose the encoding, then click Reinterpret. If you don’t know which one, try Unicode (UTF-8), then Western (Windows Latin 1). See Open a document in a different encoding.

  • Help Graupel guess right next time. Move the encodings you use toward the top of the encoding list. See Change the encoding list.

  • Check the file’s own declaration. If Refer to encoding declaration in document is on in Format settings, a wrong charset= or coding: line near the top of the file misleads Graupel. Fix the line, or turn the setting off. See How Graupel detects encodings.

If the file isn’t text at all, such as an image or a Word document, no encoding will make it readable. Open it in the app it belongs to.
