Report a problem

If something in Graupel doesn’t work as this guide describes, or Graupel quits unexpectedly, report it on GitHub.

  1. Choose Help > Create Issue Report. Graupel opens a new document with a report form, with your Graupel and macOS versions already filled in.

  2. Fill in what happened, the steps that lead to it, and what you expected.

  3. Choose Help > Report Issue to open Graupel’s issues page, start a new issue, and paste the report. You need a GitHub account.

Report a problem

When Graupel quits unexpectedly, macOS shows a dialog. Click Report to see the crash log, then copy it into your issue. A crash that happens again and again under the same conditions is the most useful to report; say what you were doing when it happened.

If a problem is with a language server

Problems with errors or suggestions in your code may come from the language server rather than Graupel. See If a language server isn’t working first.
