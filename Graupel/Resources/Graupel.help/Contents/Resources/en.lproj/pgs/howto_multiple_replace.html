Make several replacements at once

Multiple Replace runs a list of find-and-replace rules on a document, in order from top to bottom. Each list is saved as a replace definition that you can run again.

Run a replace definition

  • Choose Find > Multiple Replace, then choose the definition.

  • Or choose Find > Multiple Replace > Manage Multiple Replace, select the definition in the sidebar, then click Replace All. To limit it to the selected text, select In Selection first.

To see what the rules match before replacing, click Highlight All instead. The highlights can differ from the result of Replace All, because each rule there runs on the text the earlier rules left.

Make or change a definition

  1. Choose Find > Multiple Replace > Manage Multiple Replace.

  2. To make a definition, click the Add (+) button below the sidebar. To change one, select it.

  3. Click the Add (+) button below the rules to add a rule, then fill in its columns:

    ColumnWhat it’s for
    (checkbox)

    Deselect it to skip the rule without deleting it.

    Find

    The text to find. A rule with an empty Find or an invalid regular expression is skipped.

    Replace With

    The new text. Leave it empty to delete the matches.

    RE

    Treats Find as a regular expression.

    IC

    Ignores case.

    Description

    A note for yourself. It doesn’t change anything.

To change the advanced find options for every rule in the definition, click the ••• button. The options are described in Find and replace text.

Changes are saved as you make them. To rename, duplicate, or delete a definition, Control-click it in the sidebar.

Share definitions

Each definition is a Graupel Replace Definition file (.cotrpl), which is JSON. Control-click a definition and choose Export… to save a copy. To add one, drag the file into the sidebar, or click the ••• button below the sidebar and choose Import….

You can also import a UTF-8 .tsv file with one rule per line: the text to find, a tab, then the replacement. TSV can’t store options such as RE or IC, so set those after importing.
