Make or change a syntax

You can change a built-in syntax or make one for a language Graupel doesn’t know. Both are done in the syntax editor.

Open the syntax editor

  1. Choose Graupel > Settings, then click Format.

  2. Under Available syntaxes, do one of the following:

    • To change a syntax, double-click it, or select it and click the Edit (pencil) button below the list.

    • To make a new one, click the Add (+) button below the list.

Changes to a built-in syntax are saved as your own copy. To go back to the original, select the syntax, click the ••• button, then choose Restore.

What you can set

At the top of the editor, type the syntax’s name and choose its Kind: general or code. The kind picks the mode. The sidebar has these panes:

  • File Mapping: the file extensions, file names, and #! interpreters that use this syntax.

  • Delimiters: comment characters, the brackets that start and end blocks, and how strings escape characters.

  • Outline: the patterns that find outline items.

  • Completion: words to add to the suggestions.

  • Highlighting: one pane for each kind of text, such as Keywords, Strings, and Comments.

  • Information: version, author, license, and other notes about the syntax.

  • Validation: lists problems in the definition, such as invalid regular expressions or duplicate entries.

Regular expressions and tree-sitter

Most syntaxes find keywords, strings, and outline items with lists and regular expressions. You can change all of it in the syntax editor. Boreas works this way.

Some built-in syntaxes use tree-sitter instead, which reads the code’s grammar and is more accurate with nested or multi-line code. These are Bash, C, C++, C#, CSS, Go, HTML, Java, JavaScript, Kotlin, LaTeX, Lua, Makefile, PHP, Python, Ruby, Rust, Scala, SQL, Swift, and TypeScript. Markdown uses tree-sitter for its outline only. You can’t change tree-sitter rules or add tree-sitter to other syntaxes.

Share a syntax

A syntax is saved as a Graupel Syntax file (.cotsyntax).

  • To export, select your syntax, click the ••• button, then choose Export…. Or drag it from the list to the Finder. Only syntaxes you made or changed can be exported.

  • To import, click the ••• button and choose Import…, or drag a .cotsyntax file into the list. Older syntax files in YAML format are converted when you import them.

To move all your syntaxes and settings to another Mac at once, see Move your settings to another Mac.
