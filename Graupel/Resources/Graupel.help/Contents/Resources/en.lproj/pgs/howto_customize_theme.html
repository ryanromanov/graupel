Change the colors

A theme sets the editor’s colors: the text, the background, the selection, and a color for each kind of highlighted text, such as keywords and comments. Graupel comes with several themes, and you can change them or make your own.

Choose a theme

Choose Graupel > Settings, then click Appearance. There are two theme menus:

  • Window theme colors the title bar, sidebar, bars, and Run panel. Choose Graupel or Rain.

  • Editor theme colors your text. Match Window uses the window theme. You can instead choose any theme, including your own.

The menu beside each theme makes it Light or Dark, or lets it follow your Mac (Match System). For example, you can use a light Graupel window around a dark Rain editor.

To make your own light and dark pair, give the dark theme the same name as the light one followed by a space and “(Dark)”. The light one can also end in “(Light)”. The Editor theme menu lists a pair once.

Change or make a theme

  1. In Appearance settings, click Create or Edit Theme.

  2. In the Theme list, select the theme to change. To start from a copy, Control-click it and choose Duplicate. To start from scratch, click the Add (+) button.

  3. Click a color, then choose the new color in the Colors window. The editor changes as you go, and the theme is saved as you change it.

For the cursor, the selection, and the highlight, you can select Use system color to use the accent and highlight colors from System Settings instead.

Changing a built-in theme saves your own copy of it. To go back to the original, Control-click it and choose Restore.

Share a theme

A theme is saved as a Graupel Theme file (.cottheme), which is JSON with colors written as hexadecimal values in the Generic RGB color space.

  • To export, Control-click your theme and choose Export…, or drag it to the Finder. Built-in themes you haven’t changed can’t be exported.

  • To import, click Create or Edit Theme, then drag a .cottheme file into the list, or click the ••• button below the list and choose Import….
