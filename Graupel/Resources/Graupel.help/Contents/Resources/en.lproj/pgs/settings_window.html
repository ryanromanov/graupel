Window settings

Choose Graupel > Settings, then click Window.

SettingWhat it does
Open documents in tabs

When a document opens as a tab instead of a new window: Always, Automatically (in full screen, or when you open several at once), Never, or Respect System Setting, which uses Prefer tabs when opening documents in System Settings > Desktop & Dock.
Window size

The width and height of new windows, in pixels. Leave a field empty (Auto) to use the size of the last window.
Show

Line numbers in the margin, Invisible characters (you choose which: Line ending, Tab, Space, Other whitespace, and Other control characters; see Show invisible characters), Indent guides at each indent level, and a Page guide at column, a line after the column you choose.
Current line

Change background color highlights the line with the insertion point, using the theme’s Current Line color.
Line wrapping

Wrap lines to editor width wraps long lines instead of scrolling sideways. Indent wrapped lines by indents the continued part of a line by the number of spaces you choose, on top of the line’s own indentation.
Writing direction

Left to right, Right to left, or Vertical, for new documents.
Overscroll

How far you can scroll past the last line. At 0%, scrolling stops at the end; at 100%, you can scroll until only the last line is showing.
Status bar shows

What the status bar at the bottom of the window shows: Line count, Character count, Word count, Location, Current line, and Current column. It always shows the file size, the text encoding, and the line endings, and the problem under the insertion point when a language server reports one.
