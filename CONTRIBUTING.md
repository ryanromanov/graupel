# Contributing

Graupel is a small project in early development. Bug reports and suggestions are welcome on the
[Issues page](https://github.com/ryanromanov/graupel/issues), one topic per issue.

Graupel is based on CotEditor, but please report Graupel's issues here, not to CotEditor, even when the issue
looks like it comes from CotEditor's code.

Before working on a pull request, please open an issue to discuss the change.
