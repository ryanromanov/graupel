Insert a snippet

A snippet is text you save once and insert when you need it. Graupel has two kinds: command snippets, which you insert from a menu or with a keyboard shortcut, and file drop snippets, which go in when you drag a file into a document.

To make or change snippets, choose Graupel > Settings, then click Snippets.

Insert a command snippet

Choose Text > Insert Snippet, then choose the snippet. Or press the shortcut you gave it.

A snippet can wrap the selected text or put the insertion point at a set place inside it. See Snippet variables.

If you set a Syntax for a snippet, it appears in the menu, and its shortcut works, only in documents with that syntax.

Insert text by dropping a file

Drag a file from the Finder or another app to the place in the document where you want the text. Graupel inserts the text of the file drop snippet that matches the file’s extension and the document’s syntax. For example, dropping an image into an HTML document inserts an <img> tag that points to it.

If no snippet matches, Graupel inserts the file’s path.
