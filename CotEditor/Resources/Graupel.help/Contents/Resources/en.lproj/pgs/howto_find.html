Find and replace text

Graupel finds text in the front document and can replace it, using plain text or regular expressions.

Find text

  1. Choose Find > Find (Command-F). The Find & Replace window opens.

  2. Type what you’re looking for in the Find field.

  3. Click Find Next or Find Previous, or press Command-G or Command-Shift-G.

To list every match, click Find All. Its menu also has Highlight All, which colors every match in the document, and Select All, which selects them so you can edit them at once. To remove highlights, choose Find > Remove Highlights.

To use earlier searches again, click the magnifying glass in the Find field.

Replace text

  1. Type the new text in the Replace with field. Leave it empty to delete each match.

  2. Click Replace to replace the current match and find the next one, or Replace All to replace every match.

To type a line break in either field, press Option-Return. To type a tab, press Option-Tab.

Search options

These are below the fields.

OptionWhat it does
Regular Expression

Treats the Find field as a regular expression. Click the question mark next to it for a short syntax reference. See Regular expressions.

Ignore Case

Matches upper- and lowercase letters alike.

In Selection

Searches only the selected text.

OptionWhat it doesDefault
Match only whole words

Skips matches inside longer words.

Distinguish characters strictly

Matches only identical characters. For example, “é” typed as one character doesn’t match “e” followed by a combining accent.

Off
Ignore diacritical marks

Matches letters with or without accents, so “o” finds “ö”.

Off
Ignore width differences

Matches full-width and half-width forms, so “a” finds “ａ”.
