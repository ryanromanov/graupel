Go to a definition

When a language server supports it, Graupel can take you to where a name is declared and show what the name is when you hold the pointer over it. Both come from the document’s language server; see Language servers.

Go to where a name is declared

  • Command-click the name.

  • Or put the insertion point in the name and choose Find > Jump to Definition (Control-Command-J).

Graupel selects the name where it’s declared. If that’s in another file, Graupel opens the file. If the server can’t find a declaration, Graupel beeps. If the document’s language server doesn’t support going to definitions, Jump to Definition is dimmed and Command-click beeps.

To add an insertion point with the mouse instead, Control-Shift-click. See Type in several places at once.

See what a name is

Rest the pointer on a name for about half a second. A small window shows what the language server says about the name, such as how it’s declared. Moving the pointer off the name, typing, scrolling, or clicking closes it.

On a problem’s dotted underline, the problem’s message shows instead. See See problems in your code.

In Boreas

The Boreas server finds the names declared in the same file: variables, parameters, functions and subroutines, records, record fields after a dot, and modules and the names imported from them. Holding the pointer over a name shows its declaration; over a built-in function, it says so.
