Type a character by its code point

If you know a character’s Unicode code point, you can insert it without finding it in the Character Viewer.

  1. Click where you want the character.

  2. Choose Edit > Insert by Unicode Code Point.

  3. Type the code point in hexadecimal. As you type, Graupel shows the character and its name. To use one you inserted before, click the menu next to the field.

  4. Press Return.

You can type the number alone or after U+, 0x, or \u. 1F603, U+1F603, 0x1F603, and \u1F603 all insert “😃”.
