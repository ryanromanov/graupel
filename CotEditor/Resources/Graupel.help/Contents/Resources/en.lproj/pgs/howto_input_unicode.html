Unicode characters

Graupel can tell you what a character is, insert one by its code point, and make characters that look alike match.

Unicode characters

Select one character and choose Text > Inspect Character. Graupel shows the character enlarged, with its Unicode code point, name, block, category, and the Unicode version that added it.

Some characters you see as one, such as many emoji or letters with accents, are made of several Unicode characters. The inspector lists each of them.

To switch a block’s name between your language and its official Unicode name, click the name.

Unicode characters

If you know a character’s Unicode code point, you can insert it without finding it in the Character Viewer.

  1. Click where you want the character.

  2. Choose Edit > Insert by Unicode Code Point.

  3. Type the code point in hexadecimal. As you type, Graupel shows the character and its name. To use one you inserted before, click the menu next to the field.

  4. Press Return.

You can type the number alone or after U+, 0x, or \u. 1F603, U+1F603, 0x1F603, and \u1F603 all insert “😃”.

Unicode characters

Some characters can be stored more than one way. “é” can be a single character, or an “e” followed by a combining accent. They look the same, but a search for one won’t find the other, and tools that compare text treat them as different. Normalizing converts the text to one consistent form.

Normalize text

  1. Select the text.

  2. Choose Text > Unicode Normalizations, then choose a form.

If you’re not sure which form to use, choose NFC. It’s what most files and websites use.

Forms

FormWhat it does
NFC

Combines characters where possible, so “e” plus an accent becomes “é”.

NFD

Splits characters into a base letter and combining marks, so “é” becomes “e” plus an accent.

NFKC

Like NFC, and also replaces compatibility characters with their plain forms. For example, “ﬁ” becomes “fi” and full-width “Ａ” becomes “A”.

NFKD

Like NFD, and also replaces compatibility characters with their plain forms.

NFKC Case-Fold

Applies NFKC, makes letters lowercase for comparison, and removes characters that are normally invisible.

Modified NFD

The variant of NFD that the Mac’s older HFS+ file system uses for file names. It isn’t a Unicode standard.

Modified NFC

The matching variant of NFC. Use these two forms on text copied from Mac file names.
