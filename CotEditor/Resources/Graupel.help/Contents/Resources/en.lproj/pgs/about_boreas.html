Write Boreas

Boreas is a small programming language with Fortran’s look and stricter rules. Graupel was made for it first and supports it without any setup beyond installing Boreas.

Install Boreas

Graupel checks Boreas files with the boreas command, which comes with Boreas. Install Boreas as its README on GitHub describes. To check that it worked, run this in Terminal:

boreas --help

If Graupel was open while you installed Boreas, quit Graupel and open it again.

What Graupel does with Boreas files

  • Opens files ending in .bor, which Finder shows with the Boreas icon.

  • Colors keywords, types, built-in functions, numbers, strings, and comments.

  • Lists the programs, modules, records, functions, and subroutines in the outline. See Inspect the outline of a document.

  • Underlines errors as you type. Boreas stops at the first error in a file, so Graupel shows one error at a time; fix it to see the next. See See problems in your code.

  • Suggests the names declared in your file, the fields of a record after you type a dot, built-in functions, and keywords. See Complete words.

Graupel doesn’t run programs. To run one, use Terminal:

boreas program.bor
