Open a document in a different encoding

A text encoding is the rule that turns a file’s bytes into characters. Most files today are UTF-8, but older files, and files from Windows, often use another encoding. If Graupel reads a file with the wrong one, the text shows up as nonsense characters. Opening it with the right encoding fixes that.

Choose the encoding when you open a document

  1. Choose File > Open, then select the document.

  2. Choose an encoding from the Text encoding menu.

  3. Click Open.

The menu starts at Automatic, which lets Graupel work out the encoding (see How Graupel detects encodings). Documents you open any other way, such as by double-clicking or dragging, also use Automatic.

Reopen an open document in another encoding

  1. Choose Format > Text Encoding, or click the encoding in the status bar, then choose an encoding.

  2. Click Reinterpret.

Graupel reads the file again from disk, so any changes you haven’t saved are lost. If there are some, Graupel asks first.

If an encoding isn’t in the menu, add it to the list. See Change the encoding list.
