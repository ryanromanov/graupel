Open a document with a specified encoding

You can open a document by interpreting it with a specified text encoding. This is useful when a document doesn’t appear correctly or appears garbled.

Tip: If you don’t see the encoding you want in the Text Encoding menu, you may be able to add it by customizing the list. For details, see Change the priority of text encodings.

Specify the encoding when opening a document

  1. Choose File > Open.

  2. Select the document you want to open.

  3. Open the Text Encoding pop-up menu, then select the encoding you want to use.

  4. Click Open.

The default setting is Automatic. When Automatic is selected, Graupel chooses the most appropriate encoding based on the document’s content. For details, see Detect a document’s text encoding.

If you open a document by dragging it to the Graupel’s app icon, Graupel uses an automatically detected encoding. If you need to open a document with a specific encoding, use the Open dialog.

Reinterpret a document using a different encoding

If a document doesn’t appear correctly, you may be able to fix the issue by reinterpreting it using a different encoding.

To reinterpret an open document using another encoding, do the following:

  1. Open a document.

  2. Click the Text Encoding button in the status bar, or choose Format > Text Encoding.

  3. From the list, select the encoding you want to use.

  4. In the “Text encoding change” dialog that appears, click Reinterpret.

Note: When reinterpreting a document using a different encoding, any unsaved changes are lost. To preserve the content, save a copy beforehand.
