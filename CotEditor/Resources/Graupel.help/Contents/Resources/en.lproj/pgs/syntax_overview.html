Syntaxes

A syntax tells Graupel what kind of document it’s looking at, such as Python, Markdown, or Boreas. Graupel picks one for each document when it opens, and uses it for:

  • Highlighting. Keywords, strings, comments, and other parts get their own colors. The syntax decides what each part is; the theme decides the colors.

  • The outline. A list of a document’s headings, functions, or other landmarks. See See a document’s outline.

  • Comments. Text > Comment > Toggle Comment (Command-/) uses the comment characters for the language.

  • Suggestions. The syntax can add its keywords to the words Graupel suggests. See Complete words.

  • The mode. Each syntax is a general kind or a code kind, and that picks the editor’s mode. See Editor modes.

A language server, if you have one for the language, adds problems and better suggestions on top of this. See Language servers.

Change a document’s syntax

Choose Format > Syntax, then choose a syntax. Or use the Syntax menu in the toolbar. To see how Graupel picks one on its own, see How Graupel picks a syntax.

Add or change syntaxes

Graupel comes with syntaxes for many languages. You can change them or add your own. See Make or change a syntax.
