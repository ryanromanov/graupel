Customize the syntax menus

Graupel includes syntax definitions for many languages and file formats. You can remove syntaxes you don’t usually use from the syntax menus so that the syntaxes you use often are easier to find.

Hiding a syntax removes it from the Syntax menus in the toolbar and the Format menu. Hidden syntaxes are still used for automatic syntax detection when you open a document or rename a file.

Choose which syntaxes appear in the syntax menus

  1. Choose Graupel > Settings, then click Format.

  2. In the “Available syntaxes” section, click at the bottom of the list, then choose Customize Syntax Menu.

  3. Select or deselect each syntax’s checkbox to show or hide it in syntax menus.

  4. To select every syntax in the list, click Select All.

  5. Click OK.
