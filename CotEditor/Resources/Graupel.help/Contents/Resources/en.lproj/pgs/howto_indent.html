Indent text

Graupel can add or remove one level of indentation at the start of each selected line.

Change the indentation

  1. Select the lines, or click in a single line.

  2. Choose Text > Indentation > Shift Right (Command-]) to indent, or Shift Left (Command-[) to outdent. You can also use the Indent button in the toolbar.

In right-to-left text, the two commands swap: Shift Left indents and Shift Right outdents.

Choose tabs or spaces, and the width

For one document, choose Format > Tab Width or Format > Use Spaces for Indentation. Otherwise Graupel takes each setting from the first of these that has one:

  1. An .editorconfig file in the file’s folder or a folder above it (see below).

  2. The file’s own indentation, when you open it, if Detect indent style on document opening is on in Edit settings. A file indented with 2 spaces keeps 2 spaces.

  3. A mode you added for the syntax, such as a Boreas mode, in Mode settings.

  4. The language’s default. Boreas uses 2 spaces, the same as boreas convert writes.

  5. The General or Code mode, if you set its indentation.

  6. Edit settings.

Graupel checks again when you save a document for the first time, save it somewhere else, or rename it, but keeps a choice you made in the Format menu.

To change the indentation already in a document, choose Text > Indentation > Convert Indentation to Spaces or Convert Indentation to Tabs.

Share settings with an .editorconfig file

An .editorconfig file lets everyone working on a project, and tools such as formatters, use the same indentation. Graupel reads three of its settings: indent_style (space or tab), indent_size, and tab_width. It ignores the others, such as end_of_line and charset. For example:

root = true

[*.bor]
indent_style = space
indent_size = 2

Graupel reads the .editorconfig in the file’s folder and in each folder above it, stopping at one that says root = true. The file closest to the document wins. For the format, see editorconfig.org.
