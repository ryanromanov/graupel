Set up a language server

Use Language Servers settings to choose the server for a language, add a server for another language, or turn checking off. To learn what a language server does, see Language servers.

To open these settings, choose Graupel > Settings, then click Language Servers.

Use a server for another language

  1. Install the language server, following its instructions. Check that its command works in Terminal.

  2. In Language Servers settings, click Add (+) below the list, then choose the language.

  3. In Command, type the command that starts the server, the way you would type it in Terminal, then press Return.

    For example, the Python server Pyright starts with pyright-langserver --stdio. The server’s documentation gives the command; look for one that uses standard input and output, often with an option such as --stdio.

Graupel starts the server for every open document in that language. Status shows where the server is running from, or why it didn’t start.

Change the server for a language

Select the language in the list and type a different command in Command. To go back to the server Graupel finds by itself, delete the command; the field then shows that server’s command in gray.

Graupel runs the command with /bin/sh, so quotes, ~, and paths with spaces work as they do in Terminal.

Turn checking off or restart a server

  • To stop using a server for a language, deselect Check language files as you type. Graupel no longer underlines problems in that language, and suggestions come from your document instead.

  • To start a server again, for example after updating it, click Restart.

  • To remove a language you added, select it and click Delete (−). Languages Graupel finds a server for by itself can be turned off but not removed.

Status messages

StatusMeaning
Running

The server is running. The path shows which program it is.

Starts when you open a file

No document in the language is open, so the server isn’t running yet.

isn’t installed

Graupel can’t find the command. Install it, or type the full path of the command in Command.

Stopped

The server quit because of an error. The message after “Stopped:” is the last thing the server reported.

Off

Checking is turned off for the language.

Use a script to start a server

If a server needs more setup than one command, put the setup in a shell script. Name it after the language, such as Boreas.sh, make it executable, and put it in ~/Library/Application Scripts/com.ryanromanov.Graupel/_Language Servers/. When Command is empty, Graupel runs the script instead of the server it would find by itself.
