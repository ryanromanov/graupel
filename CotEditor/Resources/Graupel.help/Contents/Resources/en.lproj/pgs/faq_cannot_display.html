If a document appears garbled

Garbled text usually appears when Graupel cannot detect the document’s text encoding correctly. To narrow down or solve the problem, try the following:

  • The document may appear correctly if you open it using a different text encoding.

    See Open a document in a different encoding.

  • Adjusting the encoding priorities used for automatic detection may help reduce garbled text.

    See Change the encoding list.

  • If you select “Refer to encoding declaration in document” in Format settings, Graupel also refers to encoding declarations written in the document, such as “encoding=” or “@charset,” during auto-detection. If the document contains a misleading declaration, it can cause the wrong encoding to be chosen.

    See How Graupel detects encodings.

  • If the file is not plain text, such as binary data, Graupel cannot display it correctly as text. Open the file in an app that supports its file type.
