Mode settings

Mode settings set how the editor behaves for different kinds of documents, such as whether it corrects spelling or suggests words as you type. For how modes work, see Editor modes.

To change these settings, choose Graupel > Settings, then click Mode.

Modes

OptionDescription
Mode

Select the mode to change in the list on the left. General and Code apply to documents by the kind of their syntax. Settings you add for a single syntax are listed under Syntax.
Add (+)

Add settings for one syntax by choosing it from the menu.
Delete (−)

Delete the settings for the selected syntax. General and Code can’t be deleted.

Mode options

OptionDescription
Font

Use the standard font or the monospaced font. You choose both fonts in Appearance settings.
Smart copy/paste

Add or remove spaces when you paste or drag text between words, so that the words stay separated by one space.
Smart quotes

Replace straight quotes (") with curly quotes (“ ”) as you type.
Smart dashes

Replace two hyphens (--) with a dash as you type.
Text replacement

Replace text using the replacements in System Settings > Keyboard > Text Replacements.
Add period with double-space

Type a period when you press the Space bar twice after a word.
Automatically insert closing brackets and quotes

When you type an opening bracket or quotation mark, type the closing one too and put the insertion point between them.
Check spelling while typing

Underline misspelled words in red as you type.
Check grammar with spelling

Also underline grammar problems, in blue. Hold the pointer over an underlined word to see the problem. Grammar checking isn’t available for every language.
Correct spelling automatically

Correct misspelled words as you type. To undo a correction, choose Edit > Undo.
Completion list includes

Choose where suggestions come from when the document has no language server:

  • Standard words: words from the dictionary.

  • Words in document: words that appear in the document.

  • Words defined in syntax: the words the syntax lists for completion, or if it lists none, its highlighted keywords. See Define completion candidates in a syntax.

When the document has a language server, its suggestions are used instead of these words.
Suggest completions while typing

Show the list of suggestions after you type three letters, or, with a language server, after a dot. On by default for Code. See Complete words.
Use custom settings

Use the indentation settings below for this mode or syntax instead of the ones in Edit settings.
Prefer using

Indent with Spaces (as many as the indent width) or with Tabs (one tab character). The Tab key types the same.
Indent width

The number of spaces one indent level takes, which is also how wide a tab character is shown.
