Create or open documents

Graupel edits plain text: text with no fonts, colors, or images in it. Source code, Markdown, HTML, and .txt files are all plain text. Graupel can open any file as plain text, including files made in other apps.

Create a document

Choose File > New. When Graupel opens with no other documents, it also creates a new document; to change that, use When nothing else is open in General settings.

Open a document

  • Choose File > Open, select the document, then click Open. To pick the text encoding Graupel reads the file with, see Open a document with a specified encoding.

  • Drag the document onto the Graupel icon in the Dock or the Finder.

  • Double-click the document in the Finder, if Graupel is the app that opens that kind of file.

Graupel also opens files that aren’t plain text, such as PDF or RTF files, and shows the text inside them as is. To edit them in their own format, use the app made for them.

Open a folder

Open a folder the same way as a document. Its files appear in a sidebar, and you can switch between them in one window. See Open folders.
