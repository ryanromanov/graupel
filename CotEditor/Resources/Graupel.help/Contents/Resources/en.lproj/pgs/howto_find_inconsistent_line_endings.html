Find inconsistent line endings

A document that mixes kinds of line endings, such as LF and CRLF, can break scripts and other tools. Graupel checks for this when it opens a document. To learn about the kinds of line endings, see Handle various types of line endings.

When Graupel finds mixed line endings

Graupel uses the most common line ending for the document and asks what to do with the others: convert them all to that one, or leave them so you can look first.

To stop being asked about one document, select Don’t ask again for this document. To stop being asked about any document, choose Graupel > Settings, click General, click Manage Warnings, and select Inconsistent line endings. See Manage warnings.

See where they are

  • Choose View > Inspector > Warnings. The Warnings inspector lists every line ending that differs from the document’s.

  • Show invisible characters. Line endings that differ are drawn in another color. See Show invisible characters.

Make them all the same

Choose the line ending you want from Format > Line Endings or the menu in the status bar, even if it’s already selected. Graupel converts every line ending in the document.
