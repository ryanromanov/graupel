Language servers

A language server is a program that understands a programming language. While you write, Graupel sends it your document, and the server reports the problems it finds and suggests words that fit where you’re typing. Graupel underlines the problems and shows the suggestions in the completion list.

Language servers follow a shared standard, the Language Server Protocol (LSP), so one server works in many editors. Most languages have one, often made by the people who make the language.

Servers Graupel finds by itself

For the languages it comes with a server for, Graupel looks for the server when you open a document and starts it. There’s nothing to set up beyond installing the server.

LanguageServer
Boreas

boreas lsp, part of the boreas command. See Write Boreas.

Graupel looks for a server’s command in the same folders as Terminal, using the PATH set up for your shell, and also in /opt/homebrew/bin, /usr/local/bin, and ~/.local/bin.

For any other language, you can tell Graupel which server to use. See Set up a language server.

How Graupel runs servers

Graupel runs one server for each language, shared by all your open documents in that language. The server starts when you open the first document in the language and stops when you close the last one.

If a server isn’t installed, or stops because of an error, the status bar at the bottom of the window says so, for example “Boreas server not installed”. Hold the pointer over the message to see why, or click it to open Language Servers settings.
