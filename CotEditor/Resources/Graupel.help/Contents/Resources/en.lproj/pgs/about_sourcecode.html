About Graupel

Graupel is a free text editor for the Mac that checks code and suggests words through language servers. Its source code is on GitHub.

Based on CotEditor

Graupel is a modified version of CotEditor 7.2, made by the CotEditor Project. Almost all of its editing features come from CotEditor. Graupel adds language servers, runs outside the App Sandbox so that servers can start without the menu bar showing them as running scripts, and has its own name, icons, and settings.

Graupel is a separate project. It isn’t affiliated with or endorsed by the CotEditor Project, so please report Graupel’s problems to Graupel, not to CotEditor.
