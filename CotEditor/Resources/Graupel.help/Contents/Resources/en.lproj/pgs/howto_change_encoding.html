Save a document in a different encoding

You can change the encoding a document is saved in, for example to convert an old file to UTF-8.

Change a document’s encoding

  1. Choose Format > Text Encoding, or click the encoding in the status bar, then choose an encoding.

  2. If the document has been saved before, Graupel asks what you mean:

    • Convert keeps the text as it is and saves it in the new encoding from now on. This is what you usually want.

    • Reinterpret reads the file again in the new encoding. Use it when the text looks wrong. See Open a document in a different encoding.

  3. Save the document.

A new document that hasn’t been saved changes right away, without asking.

If some characters can’t be saved

Not every encoding has every character. If the document has characters the new encoding can’t store, Graupel warns you, because those characters would be replaced or removed when you save. Click Change Encoding to go ahead. The Warnings inspector then lists the characters, so you can change them. See Find characters the encoding can’t save.

Change the encoding for new documents

Choose Graupel > Settings, click Format, then choose an encoding from Default text encoding. It’s UTF-8 unless you change it.
