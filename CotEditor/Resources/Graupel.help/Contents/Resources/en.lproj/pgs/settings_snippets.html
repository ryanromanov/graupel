Snippets settings

Choose Graupel > Settings, then click Snippets. The pane has two tabs: Command for snippets you insert from the menu or with a shortcut, and File Drop for text inserted when you drag a file into a document. See Insert a snippet.

Command snippets

Click the Add (+) button to add a snippet, then fill in its columns:

  • Syntax: the syntax the snippet works in. All means every document.

  • Name: the name in Text > Insert Snippet.

  • Key: a keyboard shortcut, if you want one. Click the column and press the keys.

Type the text to insert in the field below the list. Lines after the first get the indentation of the line you insert into. Two variables, which you can type or add with Insert Variable, are replaced when the snippet goes in:

VariableBecomes
<<<SELECTION>>>

The selected text, so a snippet can wrap it.

<<<CURSOR>>>

Where the insertion point goes afterward. Use it more than once for several insertion points.

For example, if <<<CURSOR>>> then, then a new line with <<<SELECTION>>>, then end if wraps the selected Boreas code in an if block and puts the insertion point where the condition goes.

File drop snippets

When you drop a file into a document, Graupel checks this list from the top and uses the first item whose Syntax and Extensions match. Type extensions without periods, separated by commas; leave the column empty to match every file. Description is a note for yourself. If nothing matches, Graupel inserts the file’s path. To go back to the original list, click Restore Defaults.

These variables are replaced with details of the dropped file:

VariableBecomes
<<<ABSOLUTE-PATH>>>

The file’s full path.

<<<RELATIVE-PATH>>>

The path from the document to the file, or the full path if the document hasn’t been saved.

<<<FILENAME>>>

The file name, such as photo.jpg.

<<<FILENAME-NOSUFFIX>>>

The name without its extension, such as photo.

<<<FILEEXTENSION>>>

The extension as written. <<<FILEEXTENSION-LOWER>>> and <<<FILEEXTENSION-UPPER>>> give it in lowercase or uppercase.

<<<DIRECTORY>>>

The name of the folder the file is in.

<<<FILECONTENT>>>

The file’s text, if it’s a UTF-8 text file.

<<<IMAGEWIDTH>>>, <<<IMAGEHEIGHT>>>

An image’s width and height in pixels.

For example, <img src="<<<RELATIVE-PATH>>>" width="<<<IMAGEWIDTH>>>"> inserts <img src="photo.jpg" width="160"> when you drop a 160-pixel-wide photo.jpg from the document’s folder.
