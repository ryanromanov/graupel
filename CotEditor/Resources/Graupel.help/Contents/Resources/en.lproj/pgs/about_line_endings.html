Line endings

Different systems end lines with different characters. Graupel uses one kind of line ending throughout a document, and you can change which.

NameCharactersIn regular expressionsUsed by
LF (Line Feed)U+000A\n

macOS, Linux, and other UNIX systems.

CR (Carriage Return)U+000D\r

Mac OS before Mac OS X.

CRLFU+000D U+000A\r\n

Windows.

NEL (Next Line)U+0085

Some IBM systems.

LS (Line Separator)U+2028

Unicode’s own line separator.

PS (Paragraph Separator)U+2029

Unicode’s own paragraph separator.

NEL, LS, and PS are rare, so Graupel lists them only when you hold down the Option key. Vertical tab (U+000B) and form feed (U+000C) also start a new line on screen, but Graupel doesn’t count them as line endings.

See and change a document’s line endings

When you open a document, Graupel uses the kind of line ending it finds most often. The status bar shows it, as do the Document inspector and Format > Line Endings.

To change it, choose a different line ending from the menu in the status bar or from Format > Line Endings. Graupel converts every line ending in the document. To choose NEL, LS, or PS, hold down the Option key while the menu is open.

For new documents, choose Graupel > Settings, click Format, then choose from Default line endings. Graupel also uses it for documents that have only one line.

Mixed line endings

A document that mixes kinds of line endings, such as LF and CRLF, can break scripts and other tools. Graupel checks for this when it opens a document. It uses the most common line ending and asks what to do with the others: convert them all to that one, or leave them so you can look first.

To stop being asked about one document, select Don’t ask again for this document. To stop being asked about any document, choose Graupel > Settings, click General, click Manage Warnings, and select Inconsistent line endings.

To see where they are, choose View > Inspector > Warnings, which lists every line ending that differs from the document’s. Or show invisible characters: line endings that differ are drawn in another color.

To make them all the same, choose the line ending you want from Format > Line Endings or the menu in the status bar, even if it’s already selected.

Paste text

When you paste with Edit > Paste (Command-V), Graupel changes the line endings in the pasted text to match the document’s. To paste text exactly as it is on the clipboard, press Command-Option-V, or hold down the Option key and choose Edit > Paste Exactly. This can leave the document with mixed line endings.

Find and replace line endings

A line break you type in the Find field with Option-Return stands for the document’s own line ending. If the document uses LF, it won’t match a stray CRLF. This is true with or without Regular Expression.

With Regular Expression on, you can name a line ending exactly instead: \n for LF, \r for CR, \r\n for CRLF, or \R for any line ending, including U+000B, U+000C, U+0085, U+2028, and U+2029. In an LF document, \r\n|\r finds every line ending that doesn’t match.

Every line ending that a replacement puts in becomes the document’s line ending. That includes \r or \n in the Replace with field and line endings inside captured text. For example, in an LF document, replacing dog\Rcow with $0\r turns “dog\r\ncow” into “dog\ncow\n”.

To put in a line ending of another kind on purpose, type it by its code point (see Unicode characters) or use Paste Exactly.
