Find text in a folder

When you’ve opened a folder, you can search the text of all its files from the sidebar. To find files by name instead, use the filter field at the bottom of the file list.

Search a folder

  1. Open a folder. See Open folders.

  2. In the sidebar, click Folder Find.

  3. Type in the Search in Folder field, then press Return.

  4. Click a file or a matching line in the results. The file opens in the window, with the match selected if you clicked a line.

To search with a regular expression, choose Regular Expression from the menu above the field. To match capital and small letters exactly, click Case Sensitive.

Search only some files

  1. From the scope menu below the field, choose Edit File Scope.

  2. Add rules for the file name, path, or extension, and choose whether a file must match any or all of them. For example, to skip generated files, add “File path does not contain build”.

To use the same rules again, click Save as Named Scope and give them a name; they then appear in the scope menu of every folder. To change or delete saved scopes, choose Manage Saved Scopes. To search every file again, choose Clear File Scope.

What gets searched

  • Only files Graupel can read as text. The scope menu can add other kinds of files, but files that turn out not to be text are skipped.

  • Not hidden files, unless you choose Include Hidden Files. .DS_Store files and .git folders are always skipped.

  • Not files larger than 1 GB, and not the originals of aliases and symbolic links.

  • Up to 5,000 matches in a file and 500,000 in all. The results say when there are more.
