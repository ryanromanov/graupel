Run your program

Graupel can run the document you’re editing and show what the program prints in the Run panel, below the editor. Boreas files run with the boreas command. For another language, set a run command first; see Set the command for a language.

Run a document

Choose Run > Run (Command-R), or click the Run button (▶) in the Run panel.

Graupel saves the document, then runs the saved file from the folder it’s in, so a program that opens files by a relative path finds them there. If the document has never been saved, Graupel asks where to save it first; if you cancel, nothing runs.

Each window runs one program at a time. If you run again while a program is still running, Graupel stops it first.

Read the output

The Run panel shows the output as the program prints it. Errors the program reports are red, and text you send to the program is in your accent color.

The top of the panel shows the command that ran and how the program is doing:

MessageMeaning
Running

The program hasn’t ended yet.

Finished in

The program ended without an error. The time is how long it ran.

Ended with status

The program ended with an exit status other than 0, which usually means an error.

Stopped after

You stopped the program.

Ended by signal

Something other than Stop ended the program, such as a crash.

Couldn’t start

The command couldn’t be started. The message gives the reason.

The panel keeps the last million or so characters of output. To empty it, click the Clear button (trash can); a program that’s still running keeps running.

Type input for the program

While a program runs, the bottom of the Run panel has an input field. When the program asks for input, such as with read_line in Boreas, type a line in the field and press Return to send it.

Stop a program

Choose Run > Stop (Command-Period), or click the Stop button (■) in the Run panel. Graupel interrupts the program, as Control-C does in Terminal, and if it’s still running after 2 seconds, Graupel forces it to quit.

Closing the window or quitting Graupel also stops a running program.

Show or hide the Run panel

Choose Run > Show Run Panel or Hide Run Panel (Shift-Command-R), or click the Hide button (⌄) in the panel. Running a document shows the panel. To change the panel’s height, drag the line above it.

Set the command for a language

Graupel runs a document with the command for its syntax. Boreas’s command is boreas. To run another language, or to change how Boreas files run:

  1. Choose Graupel > Settings, then click Language Servers.

  2. Select the language in the list. If it isn’t listed, click Add (+) below the list and choose it.

  3. In Run, type the command, the way you would type it in Terminal, then press Return. For example, type python3 for Python.

Graupel adds the file’s path at the end of the command and runs it with /bin/sh, so quotes, ~, and paths with spaces work as they do in Terminal. To go back to the command Graupel uses by itself, delete the command.

If a language needs more than one command to run, put them in a shell script. Name it after the language, such as Python.sh, make it executable, and put it in ~/Library/Application Scripts/com.ryanromanov.Graupel/_Run/. The script gets the file’s path as its first argument. When Run is empty, Graupel uses the script.

If a language has no run command, the Run panel says so. If Graupel can’t find the command, install it, or type its full path in Run.
