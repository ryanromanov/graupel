Format settings

Choose Graupel > Settings, then click Format.

SettingWhat it does
Default line endings

The line ending for new documents, and for opened documents that have only one line. See Line endings.
Default text encoding

The encoding for new documents.
Encoding priorities

Click Edit List… to choose which encodings Graupel offers and tries, and in what order. See Change the encoding list.
Refer to encoding declaration in document

Uses a declaration such as charset=utf-8 near the top of a file to pick its encoding. See How Graupel detects encodings.
Default syntax

The syntax for new documents.
Available syntaxes

Every syntax, built-in and your own. A dot before a name means you’ve changed it. Below the list:

  • Add (+) makes a new syntax, Delete (−) deletes one of yours, and Edit (pencil) opens the selected one in the syntax editor. See Make or change a syntax.

  • The ••• button has Duplicate, Restore (undo your changes to a built-in syntax), Export…, Import…, Customize Syntax Menu… (see Shorten the syntax menus), and Show File Mapping Conflicts (see How Graupel picks a syntax).
