Find and replace line endings

Line endings can be LF, CR, or CRLF (see Line endings). How a search matches them depends on how you typed them.

Find line endings

A line break you type in the Find field with Option-Return stands for the document’s own line ending. If the document uses LF, it won’t match a stray CRLF. This is true with or without Regular Expression.

With Regular Expression on, you can name a line ending exactly instead:

PatternMatches
\n

LF (U+000A)

\r

CR (U+000D)

\r\n

CRLF

\R

Any line ending: LF, CR, CRLF, and the less common U+000B, U+000C, U+0085, U+2028, and U+2029.

To find every line ending that doesn’t match the document’s, search for \r\n|\r in an LF document. Or use Find inconsistent line endings.

Replace with line endings

Every line ending that a replacement puts in becomes the document’s line ending. That includes \r or \n in the Replace with field and line endings inside captured text.

For example, in an LF document, replacing dog\Rcow with $0\r turns “dog\r\ncow” into “dog\ncow\n”, not “dog\r\ncow\r”.

Find and replace can’t insert a line ending of another kind. To change all of a document’s line endings, use Format > Line Endings.
