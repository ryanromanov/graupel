Release notes

What changed in each version of Graupel. Graupel 0.1 is based on CotEditor 7.2; for changes before Graupel, see CotEditor’s change log.

Graupel 0.4.2

released 2026-11-11

Fixes

  • Fix syntax highlighting taking minutes on large files. A 10 MB Boreas file took 51 seconds to highlight and now takes about 13.

Graupel 0.4.1

released 2026-11-09

Notes

  • This release checks that Graupel 0.4.0 can update itself. Nothing else changed.

Graupel 0.4.0

released 2026-11-09

New Features

  • Graupel now updates itself. It checks for a new version once a day, or when you choose Graupel > Check for Updates, and shows what changed before installing. Change this under Updates in General settings. See Update Graupel.

Notes

  • Graupel 0.3.1 and earlier can’t update themselves, so this version has to be installed by hand or with Homebrew.

Graupel 0.3.1

released 2026-11-09

Improvements

  • Boreas: the new built-in function cshift is highlighted.

Fixes

  • Document windows no longer ask the App Store about a donation subscription, which was left over from CotEditor.

Graupel 0.3.0

released 2026-11-08

New features

  • Go to where a name is declared: Command-click it, or choose Find > Jump to Definition (Control-Command-J). Rest the pointer on a name to see what it is. Both need a language server that supports them, as the Boreas server does. See Go to a definition.

Changes

  • To add or remove an insertion point, Control-Shift-click. Command-click now goes to a definition. See Type in several places at once.

Improvements

  • A Run/Stop button for the toolbar.
  • File locations in the Run panel’s output, such as tour.bor:12:5, are links to that line.

Graupel 0.2.0

released 2026-11-08

New features

  • Run the document with Run > Run (Command-R). Graupel saves it and shows the program’s output in a Run panel below the editor, with a field for input and a Stop command. Boreas files run with boreas; set the command for other languages in Language Servers settings. See Run your program.

Changes

  • Help has Graupel’s own graphics, and the Script menu has Graupel’s own scroll icon.

Graupel 0.1.0

released 2026-11-06

New features

  • Language servers check your code as you type. Graupel underlines the problems they find and shows the one at the cursor in the status bar.
  • Suggestions from language servers: names from your file, fields after a dot, built-in functions, and keywords. Press Esc to show them at any time.
  • Graupel finds the language servers of the languages it comes with by itself. Use other servers in the new Language Servers settings.
  • The status bar tells you when a language server is missing or has stopped.
  • Boreas syntax, with its own file icon.

Changes

  • Graupel has its own name, icons, and settings.
  • The command-line tool is now called graupel.
  • Graupel doesn’t run in the App Sandbox, so language servers can start without the menu bar listing each one as a running script.
  • Suggestions while typing are on by default for code.
  • Remote editing over rmate is turned off for now.
