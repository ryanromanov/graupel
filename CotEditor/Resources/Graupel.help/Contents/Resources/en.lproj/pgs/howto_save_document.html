Save documents

Graupel saves your documents as you work, like TextEdit and Pages do. You can also turn that off, so that files change only when you save them.

Save a document

Choose File > Save. The first time you save a new document, type a name, choose a folder, then click Save.

To save a copy under another name or in another place, hold down the Option key and choose File > Save As.

How Graupel saves as you work

Graupel uses the Mac’s Auto Save with Versions. It’s on unless you turn it off with Enable Auto Save with Versions in General settings.

  • When it’s on, Graupel saves your changes to the file as you edit, and keeps earlier versions you can go back to. A new document that you haven’t saved yet is kept on your Mac until you save it.

  • When it’s off, the file changes only when you choose File > Save. Graupel keeps a copy of your unsaved changes in ~/Library/Autosave Information, so they aren’t lost if Graupel quits unexpectedly.

Go back to an earlier version

With Auto Save with Versions on, each save keeps a version of the document.

  • To go back to the version you opened or last saved, choose File > Revert To, then choose Last Opened, Last Saved, or Previous Save.

  • To look through all versions, choose File > Revert To > Browse All Versions. Click the tick marks along the timeline to move between versions, then do one of the following:

    • To replace the document with a version, click Restore below it.

    • To open a version as a new document, hold down the Option key and click Restore a Copy.

    • To go back to the document without changing it, click Done.

    You can also copy text from an earlier version and paste it into the current one.
