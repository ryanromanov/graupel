Update Graupel

Graupel looks for a new version once a day. When there is one, it shows what changed and asks whether to install it. The second time you open Graupel, it asks if it should keep checking. You can change your answer in General settings.

To look now, choose Graupel > Check for Updates.

Every update is signed. Graupel won’t install one that wasn’t signed with Graupel’s own key.

Change how updates happen

Choose Graupel > Settings, click General, then look under Updates:

  • Look for new versions automatically turns the daily check on or off. Check for Updates still works when it’s off.

  • Download and install them without asking installs an update in the background. It takes effect the next time you quit Graupel.

If you installed Graupel with Homebrew

Graupel updates itself the same way. brew upgrade leaves it alone; brew upgrade --greedy updates it too.
