Make a document read-only

You can stop a document from being edited while you read it, or lock its file so that no app can change it.

Prevent editing while it’s open

This lasts until you close the document; the file itself doesn’t change.

  • Choose Format > Prevent Editing. To edit again, choose Format > Allow Editing.

  • To open a document this way, choose File > Open and select Open as read-only, or use the --readonly option of the graupel command.

  • To switch with one click, add the Edit item to the toolbar. See Customize toolbar.

While editing is prevented, a pencil with a slash appears in the status bar. AppleScript scripts can do the same with the document’s editable property; see Automate tasks using AppleScript.

Lock the file

A locked file can’t be changed or deleted by any app until you unlock it.

  1. Move the pointer to the right of the document’s name in the title bar, then click the arrow that appears.

  2. Select Locked. To unlock the file, deselect it.

You can also lock a file in the Finder; see Lock a document on Mac.
