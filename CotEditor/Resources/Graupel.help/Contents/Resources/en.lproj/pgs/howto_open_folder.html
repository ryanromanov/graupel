Open folders

Open a folder to work on the files in it from one window. The folder’s files appear in a sidebar, and the file you click opens in the window. The sidebar is only for folders; a window that opened a single file can’t show one.

Open a folder

  • Choose File > Open, select the folder, then click Open.

  • Drag the folder onto the Graupel icon.

Work with the files

  • Click a file in the sidebar to open it in the window. A window for a folder doesn’t use tabs.

  • To find files by name, type in the filter field at the bottom of the sidebar. To show all files again, clear the field.

  • To show files that are normally hidden, Control-click in the sidebar and choose Show Hidden Files. See Open hidden files.

Files that aren’t text

When you click a file that isn’t text, such as an image or a PDF, the window shows information about it and a preview. From there you can:

  • Open it in another app with Open with External Editor, which lists the apps that can open it.

  • Open it in Graupel anyway with Open as Plain Text.

  • For an alias or symbolic link, show or open the original. See Open aliases or symlinks.
