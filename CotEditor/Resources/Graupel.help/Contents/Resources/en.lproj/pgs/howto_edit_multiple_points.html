Type in several places at once

With more than one insertion point, what you type goes in at every one of them.

Add insertion points

  • At any place: Hold down the Command key and click. Command-drag to add a selection.

  • In the same column on several lines: Hold down the Option key and drag across the lines. This makes a rectangular selection.

  • On the line above or below: Press Control-Shift-Up Arrow or Control-Shift-Down Arrow, or choose Edit > Select > Select Column Up or Select Column Down.

To remove one insertion point, Command-click it.

Go back to one insertion point

  • Click anywhere in the text without holding a key.

  • Press Esc. Graupel keeps only the first insertion point.

Languages that use an input method

When you type with an input method that has you pick from candidates, such as Japanese or Chinese, Graupel goes back to one insertion point after you type. The text goes in at that point only.
