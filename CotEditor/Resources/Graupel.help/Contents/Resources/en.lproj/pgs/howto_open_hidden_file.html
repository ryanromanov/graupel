Open hidden files

Show hidden files that normally don’t appear in the Finder so you can open them in Graupel more easily.

Show hidden files in the Open dialog

  1. Choose File > Open.

  2. Select “Show hidden files.”

Show hidden files in the file browser

  1. Open a folder.

  2. Open the contextual menu in the file browser in the sidebar.

  3. Choose Show Hidden Files.

To hide hidden files again, select Show Hidden Files once more and remove the check mark.
