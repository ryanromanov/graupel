Use the graupel command

The graupel command opens files in Graupel from Terminal, and opens text piped to it as a new document. It comes inside Graupel; install it once to use it.

Install the command

The command is inside the app, at Graupel.app/Contents/SharedSupport/bin/graupel. To use it from anywhere, link it into a folder in your PATH. For /usr/local/bin, run this in Terminal:

mkdir -p /usr/local/bin
ln -s /Applications/Graupel.app/Contents/SharedSupport/bin/graupel /usr/local/bin/graupel

Integration settings show whether the command is installed. Choose Graupel > Settings, then click Integration.

The command is written in Python 3. If Terminal can’t find python3, install Apple’s command line developer tools:

xcode-select --install

The first time you use the command, macOS asks whether Terminal may control Graupel; allow it. If you didn’t, turn on Graupel under Terminal in System Settings > Privacy & Security > Automation. With the --wait option, turn on System Events there as well.

To uninstall the command, run:

rm /usr/local/bin/graupel

Examples

Open Graupel, or bring it to the front:

graupel

Open a file at line 200:

graupel --line 200 program.bor

Open a file at line 200, column 4, written the way compilers report errors:

graupel --goto program.bor:200:4

Open a file at its last line and column. Negative numbers count from the end:

graupel --line -1 --column -1 program.bor

Open text from another command as a new document:

ls -l | graupel

Use Graupel as the editor for commit messages in Git. The --wait option makes Git wait until you close the document:

git config --global core.editor "graupel --wait"

Options

OptionDescription
-w, --wait

Wait until the opened document is closed before returning to the prompt.

-g, --background

Open the file without bringing Graupel to the front.

-r, --readonly

Open the document as read-only.

-n, --new

Create a new blank document. With a file that doesn’t exist, create the file and open it.

-s, --syntax syntax

Open the document with the given syntax, such as Boreas.

-l, --line line

Move the insertion point to the line. A negative number counts from the end of the document.

-c, --column column

Move the insertion point to the column. A negative number counts from the end of the line.

--goto file[:line[:column]]

Open the file and move the insertion point to the line and column.

-h, --help

Show the options.

-v, --version

Show Graupel’s version.

A dash (-) in place of a file name reads text from standard input until it ends, then opens it as a new document.
