Automate tasks with scripts

You can add your own scripts to the Script menu in the menu bar. A script can be any of these:

  • A UNIX script in a language such as Python, Ruby, or shell. It reads text from the front document and can put its output back. See UNIX scripts.

  • An AppleScript or JavaScript for Automation (JXA) script. It can control documents, selections, and many of Graupel’s commands. See AppleScript and JXA.

Scripts written for CotEditor work in Graupel without changes.

Add a script

  1. Choose Open Scripts Folder from the Script menu. The Finder opens ~/Library/Application Scripts/com.ryanromanov.Graupel.

  2. Put your script in the folder. The Script menu updates on its own.

Arrange the Script menu

The menu follows the files and folders in the Scripts folder, sorted by name. You change it by renaming them:

  • Order: Start the name with a number and a closing parenthesis, such as 01)Open File.scpt. The number sorts the menu but doesn’t appear in it.

  • Submenus: Folders become submenus.

  • Separators: A file or folder named - becomes a separator line. Number it, such as 02)-, to place it.

  • Hidden files: Names that start with _ don’t appear, so you can keep libraries and settings files next to your scripts.

Give a script a keyboard shortcut

Before the extension, add a period, the modifier keys, and a key: ^ for Control, ~ for Option, $ for Shift, and @ for Command. An uppercase letter adds Shift.

File nameIn the menuShortcut
Insert Text.@e.scptInsert TextCommand-E
03)Insert Date.@~Y.scptInsert DateOption-Shift-Command-Y

The key must be a single character, so keys like F1 or Delete can’t be used. A shortcut that a menu command already uses is ignored. If two scripts share a shortcut, the one in a folder named after the front document’s syntax, such as Python, wins.

UNIX scripts

A UNIX script must be executable (chmod +x) and end in .sh, .pl, .php, .rb, .py, .js, .awk, or .swift. Its first line names the interpreter, such as #!/usr/bin/env python3. Graupel’s PATH can differ from your shell’s, so if env finds the wrong version, give the interpreter’s full path instead.

If the document has been saved, its path is the script’s first argument ($1 in a shell script, sys.argv[1] in Python). Text written to standard error appears in the Console window (Window > Console).

Input and output

To have Graupel send text to the script’s standard input, put %%%{GraupelXInput=value}%%% in a comment near the top. To have it use what the script prints, put %%%{GraupelXOutput=value}%%%. Text goes both ways as UTF-8, whatever the document’s encoding. Without these lines, the script gets no input and its output is ignored.

This Python script quotes the selected lines with “>” and reports how many it changed:

#!/usr/bin/env python3
# %%%{GraupelXInput=Selection}%%%
# %%%{GraupelXOutput=ReplaceSelection}%%%
import sys

count = 0
for line in sys.stdin:
    count += 1
    print(">" + line.rstrip())
sys.stderr.write(f"Quoted {count} lines.")

AppleScript and JXA

Save AppleScript or JXA scripts as .scpt, .scptd, or .applescript files in the Scripts folder, or run them from Script Editor. Graupel’s scripting dictionary lists everything a script can use. To open it, choose Help > Graupel Scripting Guide > AppleScript Dictionary.

The main things a script works with:

  • document has the text (contents), its selection, and settings such as encoding, line ending, tab width, coloring style (the syntax), and editable.

  • selection has contents, range, and line range. A range is {location, length}. The location counts from 0 and counts characters as you see them, so {0, 3} is the first three characters. A negative location counts back from the end of the document.

  • folder document is a window opened on a folder. Its current document is the file shown, and commands sent to the folder document go to that file.

Commands include find, replace, convert and reinterpret (encodings), shift left and shift right, comment out, sort lines, change case, normalize unicode, jump, and write to console. Changing the selection doesn’t scroll; use scroll to caret to bring it into view.

This script fixes a spelling throughout the front document, then replaces its first three characters:

tell application "Graupel"
	tell front document
		replace for "colour" to "color" with all and ignore case
		set range of selection to {0, 3}
		set contents of selection to "A"
		write to console "Done."
	end tell
end tell

Setting a document’s contents leaves all of the text selected, so set the selection’s range before you change contents of selection.

Run a script when a document opens or is saved

An AppleScript or JXA script saved as a script bundle (.scptd) can run on its own when a document is opened or saved. In Script Editor, save the script as a bundle, then add a GraupelHandlers key to the bundle’s Contents/Info.plist with the events it handles:

<key>GraupelHandlers</key>
<array>
	<string>document opened</string>
	<string>document saved</string>
</array>

Then write a handler for each event. In AppleScript:

using terms from application "Graupel"
	on document opened theDocument
		write to console "Opened " & (theDocument's name)
	end document opened
	on document saved theDocument
		write to console "Saved " & (theDocument's name)
	end document saved
end using terms from

In JXA, use functions named documentOpened and documentSaved, each taking the document.
