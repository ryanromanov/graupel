Graupel User Guide

for macOS

Table of Contents

Get started with Graupel

Graupel is a text editor for the Mac. It edits plain text of any kind, and for code it checks your work and suggests words as you type.

  • Create or open documents

Find problems as you type

For languages with a language server, such as Boreas, Graupel underlines errors while you write and suggests names that fit where you are.

  • Language servers
  • See problems in your code
  • Complete words

Write Boreas

Graupel comes with everything for Boreas: colors, an outline, checking, and suggestions. Install Boreas and open a .bor file.

  • Write Boreas

See the structure of a document

Graupel colors keywords, Markdown headings, HTML elements, and more for over 70 languages, and lists a document’s functions or headings so you can jump to them.

  • Syntaxes

Open any plain text

Graupel opens files in uncommon text encodings and with mixed line endings, and shows you where they might cause trouble.

  • Open a document with a specified encoding
  • Handle various types of line endings

Find and replace

Search with regular expressions, see every match in a list, and replace text with several rules at once.

  • Find and replace text
  • Make several replacements at once
